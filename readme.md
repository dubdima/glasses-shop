# GoodEye — готовый сайт с умной примеркой очков для оптик

## Что это такое
GoodEye — это шаблон сайта, который любой магазин оптики может быстро настроить под себя. Покупатели могут примерить очки через камеру или загрузив фото. Сайт подсказывает, какие оправы подходят к форме лица. Есть выбор линз, корзина, оплата, отзывы.

## Главные возможности
- 📸 Сфотографировался или загрузил фото — очки на лице.
- 🤖 Сайт сам рекомендует оправы по форме лица.
- 🕶️ Оправы показываются в 3D, можно крутить.
- ⚙️ Выбираешь тип линз (солнцезащитные, с диоптриями), покрытия (антиблик, антицарапины), цвет оправы.
- 🛒 Корзина → оплата → доставка (работает с ЮKassa и другими).
- 📸 Галерея с фото реальных покупателей и отзывы.
- 📊 Видит статистику: рекламные пиксели, Яндекс.Метрика, Google Analytics, AmoCRM.
