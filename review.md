# Оценка проекта GoodEye

## 1. По каким признакам оцениваем

| Что проверяем | Что это значит | Как измерить |
|---------------|----------------|---------------|
| Конверсия воронки | Сколько дошли до покупки после примерки | % прошедших все шаги |
| Качество примерки | Насколько точно очки ложатся на лицо, удобно ли загружать фото | Оценки пользователей, время на примерку |
| Быстродействие | Как быстро открывается сайт, нет ли тормозов на телефонах | Тесты Google (Lighthouse) |
| Безопасность | Защищены ли фото людей, есть ли шифрование | SSL-сертификат, соблюдение закона |
| Простота настройки | Легко ли магазину поменять цвета, логотип, добавить свои оправы | Сколько времени уходит на адаптацию |
| Подключение сервисов | Работает ли с AmoCRM, рекламными пикселями, оплатой | Успешность интеграции с первого раза |
| Масштабирование | Можно ли добавлять новые оправы без переделки кода | Время на добавление одной оправы |
| Цена для магазина | Сколько стоит внедрение и обслуживание | Окупаемость для клиента |

## 2. Сравнение с конкурентами

| Конкурент | Сильные стороны | Слабые стороны | Чем GoodEye лучше |
|-----------|----------------|----------------|-------------------|
| Warby Parker | Отличная примерка, известный бренд | Не продаётся как шаблон, дорого | Настраиваем под любой магазин |
| Zenni Optical | Очень много оправ, низкие цены | Примерка плоская (2D), сложно выбрать | Объёмная 3D + подбор по лицу, всего 4 шага |
| Lenskart | Есть и онлайн, и магазины | Тяжёлый сайт, не подходит малому бизнесу | Лёгкий сайт для небольших оптик |
| FittingBox (B2B) | Профессиональная примерка | Сложно настроить, дорого | Магазин настраивает сам без программистов |
| Российские оптики | Знают местный рынок | Нет умной примерки | Первый готовый сайт с ИИ и фото покупателей |

**Вывод:** GoodEye подходит для небольших оптик без своих программистов — быстро настраивается и даёт качественную 3D-примерку. Прямых конкурентов в России нет.
